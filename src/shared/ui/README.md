# UI foundation

Компоненты дизайн-системы пока живут внутри `investor-cabinet`, потому что у них один потребитель и интерфейс ещё уточняется на реальных данных.

- Атомы: `Icon`, `Card`, `Skeleton`, нативные `Select` и `DateRange`.
- Молекулы: `MetricCard` и `EmptyState`.
- Токены: `src/theme/tokens.css`, а цветовые темы — `src/theme/light.css` и `src/theme/dark.css`.
- Доменные композиции находятся в `entities` и `widgets`; они не должны попадать в общий UI-слой.

Выносить этот каталог в отдельный пакет стоит после появления второго приложения-потребителя. До этого момента публичные props компонентов сохраняются без доменных типов и бизнес-логики, чтобы перенос не потребовал переписывать страницы.
